# Mavis Cookery — Trello Project Management and Slack Automation

## Project Overview

This project demonstrates how to organize tasks using Trello and automate team notifications through Slack. The board was designed to manage work progress, assign responsibilities, track checklist completion, and notify the team when tasks are completed.

## Project Objectives

- Create a Trello board for CloudMita Cookery.
- Organize work into Up Next, In Progress, and Complete lists.
- Create task cards with descriptions, checklists, and assigned team members.
- Automate Slack notifications when a card moves into the Complete list.

## Tools Used

- **Trello:** Task management, Kanban workflow, checklists, and team assignments.
- **Trello Automation (Butler):** Workflow automation.
- **Slack:** Team communication and automated notifications.
- **GitHub:** Project documentation and portfolio presentation.

## Workflow

1. Tasks are created in the Up Next list.
2. Work moves into In Progress when execution begins.
3. Completed tasks are moved into Complete.
4. An automation rule sends a notification to the designated Slack channel whenever a card enters Complete.

## Key Deliverables

- Trello board with three workflow lists.
- At least five task cards with descriptions and checklists.
- Team member assignments.
- Trello-to-Slack automation rule.
- Screenshot evidence of the board, task details, automation configuration, and Slack notification.
